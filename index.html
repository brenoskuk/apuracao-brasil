What the numbers mean

Official results. Candidate votes, section counts, and electorate totals come from TSE election 6258. Each geography can have a different source timestamp. While this page is visible, it checks TSE directly every 30 seconds. Refresh requests current TSE files immediately. Checks pause while the tab is hidden and resume when it becomes visible. TSE and its distribution network may publish less frequently, so a successful check can return unchanged counts. GitHub snapshots are a fallback if direct access fails; their scheduled updates can be delayed.

The scenario is not a validated forecast. For each state and overseas, remaining registered voters are multiplied by the valid-votes-per-registered-voter rate in its counted sections. Where that is unavailable, we use its first-round rate. We apply the current candidate split to those remaining valid votes. For states with no candidate votes, the fallback is the first-round split between the two finalists, excluding other candidates. This is an assumption about transfers, not a fitted transfer model.

The slider changes Lula’s share of remaining votes by the selected percentage points; Bolsonaro receives the balance. Counted votes never change. No probability or statistical confidence interval is claimed. Reporting order, turnout changes, transfers from eliminated candidates, and differences within states can materially change the outcome.

Deltas and freshness. Consecutive published snapshots are saved only on this browser. Missing or failed areas retain their last successful data and are marked as stale. Areas without a newer generation observed for ten minutes are flagged unless their count is final; quiet places may simply have no new count. Collection time and TSE source timestamps are separate. Bundled data is labeled until the first collection. Timestamps are shown as supplied by TSE and can reflect local time. GitHub retains collected snapshots in repository history. Older source generations are rejected; newer official corrections may reduce vote totals.

The map shows the current leader, not which candidate has won a state. Gray means no candidate votes are available. National official totals include overseas votes; state files and the national file need not update simultaneously.
